Conclusão técnica

Os {{ pacote.eventos|length }} evento(s) deste laudo conferem com os selos criptográficos registrados no momento da selagem, e os {{ pacote.selos|length }} selo(s) mostrados formam uma sequência assinada e sem quebras.

Limite do que se afirma. Isto mostra que o registro não mudou desde a selagem. Não mostra que o conteúdo do log é verdadeiro: um log forjado antes de chegar ao sistema é selado como qualquer outro. O material apoia a cadeia de custódia, mas não substitui perícia nem a avaliação de quem conduz o caso.
