{{ "Apêndice B." if completo else "3." }} Método e limites

De onde vêm os números

Todos os dados vêm da plataforma, separados por organização. O relatório não inclui o conteúdo bruto dos logs. Listas longas mostram os {{ 25 }} primeiros itens.

O que este relatório não diz

  • Só enxerga o que as fontes conectadas enviam. Ativo sem agente, ou desconectado, fica fora.
  • Poucos alertas não provam que nada aconteceu: uma técnica sem regra não aparece.
  • O alerta traz o que foi registrado no log, e a origem de um log pode ser forjada.
  • A localização por endereço é uma estimativa.
  • A marcação de normas ajuda a reunir evidências, mas não atesta conformidade.

MITRE ATT&CK e D3FEND são marcas da The MITRE Corporation. As descrições de regras e o texto dos alertas aparecem como foram registrados.
