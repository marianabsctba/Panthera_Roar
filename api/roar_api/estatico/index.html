    Como escrever uma consulta

    Digite palavras para buscar no log, ou combine campos. Em português ou inglês.

    sshd falha
    logs com as duas palavras
    "falha de login"
    a frase exata
    ativo=srv-rh
    igual a
    origem!=10.*
    diferente de, com * como curinga
    usuario~mar
    contém
    nivel>=10
    maior ou igual; também >, < e <=
    a=1 E (b=2 OU NAO c=3)
    E, OU, NAO e parênteses, ou AND, OR, NOT
    | contar por usuario
    quantos logs por valor; ou stats count by, top
    | campos ativo, origem
    quais colunas mostrar; ou fields
    | ordenar -quando
    ordem, com - para decrescente; ou sort
    | limite 10
    quantos resultados; ou head

    Campos com nome simples: ativo, origem, destino, usuario, fonte, tipo, programa, protocolo, log, quando, regra e nivel. Qualquer outro campo vale pelo nome técnico, como data.win.system.eventID.

    Ativos com agente

    Syslog

    Para firewall, switch e outros equipamentos que não aceitam agente. O syslog não é cifrado: use em rede de confiança.

    Nuvem

    A credencial é guardada cifrada e nunca volta para a tela. Este coletor ainda não foi testado com uma conta real.

    Webhook

    Para qualquer sistema que saiba enviar JSON. Cada endereço tem um token próprio, que aparece uma única vez.

    Buscar em uma API

    Para sistemas sem módulo pronto: buscamos o endereço de tempos em tempos e entregamos só o que for novo.

    Fontes configuradas

    Arquivos monitorados que foram criados, alterados ou apagados.

    Regras de comportamento

    Somam pontos no risco de cada pessoa. O alerta abre em 60 pontos, e os pontos caem pela metade a cada 24 horas.
